## 2. Deskripsi Singkat Repository
Repository ialah tempat untuk menyimpan, mengelola, serta mengatur berbagai berkas, data, atau kode sumber supaya mudah diakses

## 3. Tujuan dan kegunaan Repository
Tujuan utama dari repository ialah menjamin keamanan, kerapian, dan kemudahan akses data. Hal tersebut meminimalisir atau mencegah berkas yang berantakan. Selain itu, repository juga memiliki kegunaan seperti memungkinkan banyak programmer bekerja di proyek yang sama secara bersamaan tanpa menimpa pekerjaan satu sama lain,dan juga jika terjadinya error, tim dapat mengembalikan kode ke versi sebelumnya yang stabil.

## 4. Informasi dokumentasi kegiatan workshop
- Rangkuman materi workshop (Day 1): Prompt engineering adalah cara menulis instruksi ke AI agar hasilnya lebih tepat; prompt yang baik memuat role, task, context, dan format. Git adalah alat version control untuk mencatat perubahan file atau kode, sedangkan GitHub adalah platform online untuk menyimpan repository Git dan berkolaborasi. Alur dasar Git adalah mengubah file, menjalankan git add, lalu git commit untuk menyimpan perubahan, dan git push untuk mengirimkannya ke GitHub. Repository adalah folder proyek yang dikelola Git, commit menyimpan perubahan, branch memisahkan jalur pengembangan, dan pull request digunakan untuk mengusulkan serta mereview perubahan. Perintah pentingnya meliputi git init untuk memulai repository, git add . untuk menyiapkan perubahan, git commit -m "pesan" untuk menyimpan perubahan, git remote add origin <url> untuk menghubungkan ke GitHub, git push origin main untuk mengirim perubahan, dan git pull origin main untuk mengambil perubahan dari GitHub. Sebelum menggunakan Git, atur identitas dengan git config --global user.name "Nama Kita" dan git config --global user.email "email kita". Intinya, materi ini mengajarkan cara membuat aplikasi dengan bantuan AI lalu mengelola serta menyimpan perubahannya menggunakan Git dan GitHub.
- Point-point penting:
  1. Prompt engineering membantu mengontrol hasil AI. Manfaatnya adalah meningkatkan performa model, mengurangi bias atau
     respons tidak pantas, serta membuat hasil lebih terprediksi.
  2. Git adalah version control system. Git mencatat siapa, kapan, dan perubahan apa yang dilakukan pada file, sehingga
     riwayat proyek dapat dilacak.
  3. GitHub adalah platform untuk menyimpan repository Git secara online. GitHub digunakan untuk berbagi kode dan
     berkolaborasi dengan orang lain, sedangkan Git bekerja di komputer lokal.
  4. Alur kerja Git: working directory → staging area → repository. Perubahan file pertama berada di working directory, lalu
     dipindahkan ke staging area dengan git add, dan disimpan permanen melalui git commit.
  5. Repository, commit, branch, dan pull request adalah konsep utama GitHub. Repository menyimpan proyek, commit menyimpan
     perubahan, branch memisahkan jalur pengembangan, dan pull request digunakan untuk mengusulkan serta mereview perubahan.
